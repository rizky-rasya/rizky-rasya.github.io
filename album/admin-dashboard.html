Tema & Bingkai Foto

Warna dan gaya bingkai ini dipakai di halaman kirim momen, album, dan saat tamu mengunduh foto/video/suara.

Dipakai untuk jenis media manapun yang tidak memakai template custom di bawah.

Kalau AKTIF: bingkai langsung "dibakar" ke hasil rekaman foto/video/VN saat tamu mengambil momen — jadi tombol "Unduh Berbingkai" tinggal kirim file aslinya (instan, tidak perlu proses ulang). Kalau MATI: bingkai baru ditambahkan saat tombol "Unduh Berbingkai" ditekan (seperti sekarang, prosesnya perlu waktu terutama untuk VN/video).

Voice Note (preview hasil langsung berbentuk video+bingkai saat rekam)

Unggah PNG transparan sebagai bingkai sendiri untuk tiap jenis media. Bingkai akan otomatis disesuaikan ukurannya mengikuti ukuran foto/video/voice note tamu — tidak perlu diedit manual. File besar otomatis dikompres ke bawah 250KB.

Audiogram selalu digambar di lapisan paling atas, jadi tidak akan tertutup meskipun kamu pasang template PNG custom untuk voice note.
